# SMI Market Intelligence Snapshot V2.0.1

手机端 Binance 多维市场快照。支持 USDⓈ-M 普通永续、TradFi 永续和 Spot；仅使用公开市场数据，不需 API Key，不连接账户，不下单。

## V2.0.1 本次升级
- **压缩扫描校准**：均线压缩同时输出绝对离散度（%）与近50个有效样本的历史分位；压缩判断要求绝对离散度不高于3%，并结合BB宽度、ATR分位，避免“历史分位很低但均线实际相距很远”仍被误判为压缩。
- **预热保护**：少于400根已收盘K线时，扫描阶段标记 `insufficient_history`，置信度为 low；原始指标仍可查看，但不应当作完整趋势结论。日线历史不足时尤其注意。
- **OI语义校准**：输出15m/1h OI变化和方向性描述（rising/declining/mixed/insufficient）；不再制造未经统计校准的OI分数。OI是相邻历史采样点变化，不是与K线严格同步的资金流。
- **CVD定义明确**：标明滚动主动买卖Delta代理的计算口径；背离未识别时用 `not_detected`，不再使用容易被误读为“确认无背离”的 `none`；检测到候选背离时附带两个拐点时间。
- **Stoch RSI拆分**：分别输出 `stoch_rsi_k` 与 `stoch_rsi_d`。
- **多空比命名**：紧凑JSON改为具名字段，明确全市场账户、顶级交易员持仓、顶级交易员账户三种口径。
- **Taker Flow时间信息**：输出K线开始/结束时间、是否收盘和当前K线进度百分比，便于判断未收盘柱的统计尚未完整。
- **去除合约快照中的旧版低精度`ind`重复字段**：避免MACD等指标与V2高精度字段产生冲突；紧凑JSON版本标识升级为 `v=8`、`build=2.0.1`。

## 核心指标
- 默认多周期：15m、1h、4h、1d；可选5m、1w。
- 指标独立使用最多500根已收盘K线计算；导出K线默认每周期8根，二者互不影响。
- SMA20/50/100/200；EMA12/20/26/50/100/200；价格偏离、均线排列、绝对压缩度和历史分位。
- ATR14/20、ATR%、ATR历史分位数、ADX14、+DI/-DI。
- Bollinger(20,2)、Bandwidth、Bandwidth分位数、%B。
- RSI6/14、Stoch RSI K/D、MACD(12,26,9)、ROC9/20、CCI20。
- OI历史变化周期：5m/15m/1h/4h/1d。
- 主动买卖沿用K线taker-buy字段；滚动Delta输出20/50/100根数据、价格变化和候选背离。

## 重要口径
- 所有技术指标只用已收盘K线；导出的K线可含未收盘最新K线。
- 5m、15m、1h的当前K线可能有相同开盘时间（例如小时开始后的前15分钟），这本身不代表周期映射错误；各周期成交统计是各自周期K线从开盘到当前时刻的累计值，尚未收盘时不能当作完整周期成交量比较。
- EMA200以400根已收盘K线作为预热完成门槛；每周期输出实际可用根数、预热状态及最近收盘时间。
- CVD为最近最多100根已收盘K线的滚动主动成交Delta代理，不是跨快照永久累计CVD，也不能识别具体账户身份。
- OI变化是相邻历史采样点变化；由于接口时间粒度不同，不与K线价格变化伪装成严格同步。
- 缺失值使用null；接口不支持、请求失败和样本不足不得用0代替。
- 压缩不代表方向预测，突破候选不代表确认信号；`oi_participation`仅为变化方向描述，不是经过回测的分数。
- TradFi永续K线使用continuousKlines(contractType=TRADIFI_PERPETUAL)，普通永续使用fapi klines，现货使用Spot klines。
